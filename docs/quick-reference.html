Pocket Server

Your phone as a local server · PocketBase + file manager · v1.1

8080panel
8090site / DB

Start here — first five minutes

  1. Open Pocket Server. Allow notifications when asked — the ongoing notification is what keeps the servers alive.
  2. Unlock with 1234, then go to Security and set your own 4–8 digit PIN.
  3. Dashboard → PocketBase account: create the superuser (email + 8+ character password). Opening Admin alone cannot create it — PocketBase changed that in 0.23.
  4. Files tab: upload files. They are live at http://<phone-ip>:8090/<file>; an index.html becomes the site home page.
  5. On the phone's notification tap Battery once, to exempt the app from battery optimisation.

Ports & addresses

8080Control panel, file manager, logs
8090Hosted website (files in pb_public)
8090/_/PocketBase admin: users, collections, records
127.0.0.1The phone itself (always works)
192.168.x.xThe phone on your Wi-Fi (shown on the dashboard)

PIN

  • Default PIN is 1234; the dashboard warns until you change it.
  • Change it under Security. Every other device is signed out.
  • 5 wrong tries = 10-minute lockout (HTTP 429).
  • Forgotten PIN: Settings → Apps → Pocket Server → Storage → Clear data. This also deletes uploads and the database.

Open it from a laptop

  1. Same Wi-Fi as the phone.
  2. Dashboard → Open from another device → Copy server address.
  3. Paste into the laptop browser, e.g. http://192.168.1.42:8080.
  4. Site and admin are on the same IP, port 8090.

Keep it running

  • Notification Battery action → allow, once.
  • Samsung: Settings → Battery → Background usage limits — keep the app out of “Sleeping apps”.
  • After a reboot PocketBase starts by itself; the panel needs the app opened once.
  • Partial wake lock keeps the CPU awake while the screen sleeps.

Public tunnel (full edition)

  1. Dashboard → Public tunnel → choose Quick or Named.
  2. Quick: pick Control panel (8080) or Hosted site (the site the picker shows, on its own port) → Start. Gives a new https://….trycloudflare.com each time, plus a QR code to scan.
  3. Named: Cloudflare → Zero Trust → Networks → Tunnels → Create → copy token → paste → Save → Start. Stable hostname, token stays on the phone.
  4. Notification shows the live URL. Stop it when you are done.

cloudflared tunnel --url http://127.0.0.1:<port> is what Quick mode runs — 8090 for the primary site, 8091+ for the others.

Logs

  • Logs tab → PocketBase or Tunnel.
  • Refresh = last ~300 lines; it also updates while open.
  • Restart restarts that process without using up its crash-restart budget.
  • On a PC: adb logcat -s PocketServer PocketBase Cloudflared.

When it does not work

SymptomDo this
PIN rejected in the appYou are on a build before 1.1. Install 1.1. If you changed the PIN on an older install, clear app data.
Gate says “server is still starting”Node takes a few seconds after launch; wait, or check the notification is present.
Laptop cannot reach the phoneSame Wi-Fi network, not guest Wi-Fi; check the address on the dashboard.
Pages die when the screen sleepsBattery exemption is still off, or Samsung put the app to sleep.
INSTALL_FAILED_UPDATE_INCOMPATIBLEDebug and release builds use different keys. Uninstall the old app first (data is lost).
Unknown path on :8090 shows the siteNormal — PocketBase falls back to index.html for single-page sites.
Security in one line A tunnel puts your PIN gate on the public internet. Use a long PIN, prefer Named over Quick for anything long-lived, and stop the tunnel when you finish.
